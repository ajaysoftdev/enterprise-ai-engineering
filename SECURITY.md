# Security Policy

## Scope

This repository contains educational and demonstrator projects. Unless a project explicitly says otherwise, its services are not production-ready and must not be exposed to untrusted networks or used with confidential, regulated or customer data.

## Reporting a vulnerability

Do not publish exploit details, credentials or sensitive evidence in a public issue. Use GitHub's private vulnerability reporting feature for this repository where available. Include:
- Affected project and commit.
- Preconditions and reproducible steps.
- Security impact and realistic attack scenario.
- Suggested mitigation, if known.

Do not include real personal data, customer data, tokens, passwords or production endpoints in the report.

## Response expectations

Reports will be triaged for reproducibility, affected versions, impact and remediation options. No response-time SLA is promised for this demonstration repository.

## Current limitations

The project prototypes do not collectively provide enterprise identity, tenant isolation, production key management, tamper-proof audit storage, penetration-test assurance or regulatory certification. Refer to [Portfolio Security Baseline](docs/PORTFOLIO_SECURITY_BASELINE.md) and each project's README for specific boundaries.
