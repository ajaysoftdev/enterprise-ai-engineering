# Python Data Engineering

This area contains practical Python exercises and data-engineering experiments relevant to enterprise data platforms.

## Featured projects

- [Python batch data pipeline](../projects/python-batch-data-pipeline/README.md) — ingest CSV and JSON files, validate records, transform them into a consistent model, and produce accepted/rejected outputs.
- [Data quality framework](../projects/data-quality-framework/README.md) — define reusable validation rules, profile datasets, quarantine invalid records and publish a quality report.

## Skills covered

- Python fundamentals for data processing and automation
- File, JSON, CSV and API-based data ingestion
- Data validation, cleansing and transformation
- Batch-processing patterns, idempotency and error handling
- Logging, configuration and testable pipeline design
- Data quality checks, data contracts and reproducible examples
- Unit tests, fixtures and command-line interfaces

## Working approach

Each exercise should include its objective, assumptions, sample input, implementation, expected output and tests where applicable. Use synthetic or public data only; do not commit confidential or personal data.

Start with a small dependency-light implementation. Add external frameworks only when a project requirement justifies them. Keep ingestion, transformation, validation and output concerns separated so each can be tested independently.
