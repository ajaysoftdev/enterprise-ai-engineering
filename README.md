# Enterprise AI Engineering

A practical engineering portfolio exploring enterprise software development, AI coding agents, software quality, testing, and data engineering.

The portfolio uses documented exercises and evidence to demonstrate engineering judgement: understanding an existing codebase, defining bounded tasks, inspecting changes, testing behaviour and recording technical decisions.

## Objectives

- Explore enterprise application development through an existing Java/Spring application.
- Evaluate AI coding agents on realistic, reproducible engineering tasks.
- Review AI-generated code changes for correctness, security and maintainability.
- Practise debugging, root-cause analysis, testing and regression analysis.
- Explore Python-based data engineering and data quality patterns.
- Document architecture decisions and evaluation findings with evidence.

## Working principles

- Start by understanding the existing code and its conventions.
- Define clear scope and acceptance criteria before implementation.
- Establish a baseline before changing code.
- Verify changes through tests and other relevant checks.
- Record evidence, limitations and unresolved questions.
- Distinguish original work from adapted, open-source and AI-assisted work.
- Never claim a test, implementation or evaluation is complete without evidence.
- Do not commit confidential code, credentials, tokens or personal data.
