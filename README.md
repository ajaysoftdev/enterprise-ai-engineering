# Enterprise AI Engineering

A practical engineering portfolio exploring enterprise software development, AI coding agents, software quality, testing, and data engineering.

## Objectives

- Explore enterprise application development.
- Evaluate AI coding agents on realistic engineering tasks.
- Review AI-generated code changes for correctness and quality.
- Practise debugging, testing, and regression analysis.
- Explore data engineering and data quality patterns.
- Document engineering decisions and evaluation findings.

## Areas of Focus

| Area | Scope |
|---|---|
| Java Engineering | Application development, APIs, debugging |
| Python Data Engineering | Data processing and validation |
| AI Coding Agents | Agent-assisted engineering and evaluation |
| Code Review | Code quality, maintainability and correctness |
| Testing | Unit, integration and regression testing |
| Architecture | Application design and engineering decisions |

## Working Principles

- Use realistic engineering scenarios.
- Verify changes through executable tests.
- Document findings with supporting evidence.
- Distinguish original work from adapted and AI-assisted work.
- Acknowledge open-source projects and their licenses.
