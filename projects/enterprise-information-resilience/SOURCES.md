# Reference sources — Enterprise Information Resilience

These resources inform the design; they are not endorsements of a particular vendor or a claim that the project implements every control.

## Standards and frameworks
- [NIST AI Risk Management Framework](https://www.nist.gov/itl/ai-risk-management-framework) — risk identification, measurement, governance and monitoring for AI-assisted analysis.
- [NIST Cybersecurity Framework 2.0](https://www.nist.gov/cyberframework) — governance, protection, detection, response and recovery context.
- [W3C PROV-O](https://www.w3.org/TR/prov-o/) — represent provenance between sources, claims, evidence and derived assessments.
- [C2PA Specifications](https://c2pa.org/specifications/specifications/) — content provenance and authenticity metadata where supported by source media.

## Engineering references
- [OWASP Top 10 for LLM Applications](https://owasp.org/www-project-top-10-for-large-language-model-applications/) — prompt injection, output handling and model-integrated application risks.
- [OpenTelemetry Documentation](https://opentelemetry.io/docs/) — trace and correlate ingestion, enrichment, assessment and case workflows.
- [FastAPI Documentation](https://fastapi.tiangolo.com/) — API implementation reference.

## Apply these references to this project
Preserve original source URLs and timestamps; separate observed facts from model-generated interpretations; store evidence and provenance; expose confidence and uncertainty; require human approval for public or consequential response actions. Do not automate takedowns, public statements or accusations from model output alone.
