# Reference sources — Autonomous AI Engineering Workbench

## Agent and coding evaluation
- [SWE-bench](https://www.swebench.com/) — benchmark design and issue-resolution evaluation context.
- [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) — agent execution, tool use and tracing reference.
- [Model Context Protocol](https://modelcontextprotocol.io/specification) — tool integration contract.
- [OWASP Top 10 for Agentic Applications](https://owasp.org/www-project-top-10-for-agentic-applications/) — agent execution and tool-use threat patterns.

## Secure software delivery
- [SLSA](https://slsa.dev/spec/) — build provenance and supply-chain integrity.
- [GitHub Actions documentation](https://docs.github.com/actions) — CI workflow implementation.
- [pytest documentation](https://docs.pytest.org/) — automated test execution.
- [OpenTelemetry](https://opentelemetry.io/docs/) — agent-run and tool-call tracing.

## Apply these references to this project
Use pinned repository snapshots, repeatable task prompts, isolated disposable environments and explicit network/secret controls. Score correctness, tests, security, maintainability, time and cost separately. Record model, prompt, tool and environment versions; benchmark scores are not general guarantees of production quality.
