# Reference sources — Enterprise Data Protection

## Privacy and security frameworks
- [NIST Privacy Framework](https://www.nist.gov/privacy-framework) — privacy risk identification and governance.
- [NIST SP 800-53 Rev. 5](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final) — access control, audit, data protection and system security controls.
- [GDPR official text](https://eur-lex.europa.eu/eli/reg/2016/679/oj) — legal reference for personal-data processing, rights and accountability; applicability requires legal assessment.
- [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/) — application security requirements.

## Data governance and lineage
- [W3C PROV-O](https://www.w3.org/TR/prov-o/) — provenance model for datasets, transformations and decisions.
- [OpenLineage](https://openlineage.io/docs/) — interoperable lineage events for jobs, runs and datasets.
- [OpenMetadata documentation](https://docs.open-metadata.org/) — catalogue, ownership, classification and lineage concepts.

## Apply these references to this project
Represent purpose, owner, classification, retention and permitted use as explicit metadata. Make policy decisions explainable and auditable. Treat masking and tokenisation as separate techniques with distinct threat models; verify re-identification risk before claiming anonymisation.
