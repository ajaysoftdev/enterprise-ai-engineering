# Reference sources — Breach-Resilient Enterprise

## Security architecture and control frameworks
- [NIST SP 800-207: Zero Trust Architecture](https://csrc.nist.gov/pubs/sp/800/207/final) — resource-centric access and continuous verification.
- [NIST Cybersecurity Framework 2.0](https://www.nist.gov/cyberframework) — enterprise cyber-risk outcomes and governance.
- [NIST SP 800-53 Rev. 5](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final) — security and privacy control catalogue.
- [CISA Secure by Design](https://www.cisa.gov/securebydesign) — product security principles and accountability.

## Threats and implementation
- [MITRE ATT&CK](https://attack.mitre.org/) — adversary tactics and techniques for scenario modelling.
- [Open Policy Agent documentation](https://www.openpolicyagent.org/docs/latest/) — policy-as-code and Rego evaluation.
- [OWASP Application Security Verification Standard](https://owasp.org/www-project-application-security-verification-standard/) — application security verification requirements.
- [SLSA specification](https://slsa.dev/spec/) — software supply-chain integrity and provenance.
- [OpenTelemetry](https://opentelemetry.io/docs/) — telemetry correlation for detection and response.

## Apply these references to this project
Build threat scenarios around identity compromise, lateral movement, secret exposure, API abuse and CI/CD compromise. Demonstrate policy decisions and containment in a synthetic environment; do not connect the demo to real enterprise identity or production infrastructure.
