# Evaluation Reports

This area will contain evidence-based reports from coding-agent and engineering-task evaluations.

## Report requirements

Each report should identify:

- Task description and acceptance criteria
- Repository, branch and starting commit
- Agent/model and configuration, where known
- Prompt and relevant tool permissions
- Changes proposed and changes retained
- Tests and checks actually executed
- Defects, regressions and missed requirements
- Human review and intervention
- Limitations and reproducibility notes

Use the [agent evaluation template](templates/agent-evaluation-template.md).

## Reporting principles

Do not publish unsupported performance claims. Separate observed facts, reviewer judgement and hypotheses. Do not include confidential code, secrets or personal data.
